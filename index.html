The five checks

Every piece of work passes all five.

  1. Strangers read it

    People outside the project read it first.

  2. It gets a mark

    It is scored against a written standard.

  3. Three can say no

    Three reviewers can each send it back.

  4. Five try to break it

    Five reviewers look for faults.

  5. One last look

    A director signs it off.

Work gets sent back for six reasons. One is enough.

  • Says nothing
  • Copied
  • Stale
  • Looks like everyone else
  • Shouting
  • Boring
